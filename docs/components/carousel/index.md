# Carousel 轮播图

## API

### 属性

| 属性名 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| autoplay | 是否自动播放 | `boolean` | false |
| interval | 自动切换的时间间隔，单位为毫秒 | `number` | 3000 |
| type | carousel 的类型 | `'card'\| 'opacity'` | -- |
| loop | 是否循环显示 | `boolean` | true |
| initial-index | 初始状态激活的幻灯片的索引，从 0 开始 | `number'` | 0 |
| direction | 展示的方向 | `'horizontal'\| 'vertical'` | horizontal |
| pause-on-hover | 鼠标悬浮时暂停自动切换 | `boolean` | true |
| slides-per-view | 每一页显示的轮播图数量 | `'auto'\|number` | 1 |
| space-between | 轮播图之间的间距 | `number` | 0 |
| show-arrow | 是否显示箭头按钮 | `boolean` | false |
| show-dots | 是否展示指示点 | `boolean` | true |
