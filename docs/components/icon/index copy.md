# Icon 图标
## 基本使用

:::demo
```vue
<template>
 <s-icon name="https://vitejs.dev/logo.svg" size="30" />
</template>
```
:::

## API

### 属性

| 属性名 | 说明 | 类型 | 默认值 |备注|
| --- | --- | --- | --- |---|
|size | 图标的大小 | `'number'\|'string'` | 继承字体大小 |开发中|
|nane | 图标的名称 | `'string'` | -- |开发中|
