# 安装

```bash
npm i min-sheep-ui -S
```

```bash
yarn add min-sheep-ui
```

```bash
pnpm i min-sheep-ui -S
```

# 浏览器直接引入

## unpkg

```html
<head>
  <!-- Import style -->
  <link rel="stylesheet" href="//unpkg.com/min-sheep-ui/style.css" />
  <!-- Import Vue 3 -->
  <script src="//unpkg.com/vue@3"></script>
  <!-- Import component library -->
  <script src="//unpkg.com/min-sheep-ui"></script>
</head>
```
